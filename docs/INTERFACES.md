# Module ownership and contracts

All code imports strict immutable Pydantic models from `patchington.contracts`. Root owns contracts, config, context, models, pipeline, API and CLI. Agents own only assigned files/tests; no cross-file edits without coordination.

## Durable state (`store.py`)

`Store(database_url: str)`; `initialize()`; `enqueue(tenant: str, repo: str, pr: int, delivery_id: str, payload: dict, max_attempts: int=3)->str`; dedup same delivery; `claim(owner: str, lease_seconds: int=120, tenant_limits: dict[str,int]|None=None)->Job|None`; `heartbeat(job_id, owner, fence, lease_seconds=120)->bool`; `complete(job_id, owner, fence, result: dict)->bool`; `fail(job_id, owner, fence, error: str, retry: bool=True)->bool`; `get(job_id, tenant: str)->Job|None`; `list_jobs(tenant: str, limit: int=100)->list[Job]`; `audit(tenant, actor, action, resource, details: dict)->None`; `events(tenant, limit=100)->list[dict]`; `put_record(tenant, kind, key, value: dict)->None`; `get_record(tenant, kind, key)->dict|None`. Job is immutable dataclass with id, tenant, repo, pr, payload, status, owner, fence, attempts, result, error. Epoch fencing and lease expiry mandatory. PostgreSQL is the production implementation, SQLite is development-only with equivalent basic semantics, not scale certification. Queue receipt and initial audit atomically persisted. No Redis/in-memory production state.

## Git/workspace and evidence (`gitwork.py`, `artifacts.py`, `execution.py`)

`GitWorkspace(path: Path)` initialized from trusted local fixture or an already fetched repository. `snapshot(revision: str)->dict[str,str]` no symlinks, bounds; `candidate(patch: str, snapshot: ChangeSnapshot, policy: RepoPolicy)->Candidate`: apply to clean pinned head in private worktree, validate paths/modes, canonical commit metadata; freeze patch and tree/commit identity. Expose `checkout(revision,destination)` if needed. Do not execute repository hooks or inherit Git configuration. `ArtifactStore(root: Path).put(data: bytes)->str` returns sha256; `.get(digest)->bytes` verifies digest and refuses traversal; `.put_json(dict)->str`, `.get_json(digest)->dict`. `DockerVerifier(image: str, timeout: int=120).verify(workspace: GitWorkspace,candidate: Candidate,checks: tuple[CheckSpec,...])->Verification`: execute same trusted checks against original PR head and candidate in clean separate containers; network none, nonroot, no capabilities, read-only root, bounded memory/cpu/pids/logs/time, no secrets/socket/mount of home. Only owner-supplied check argv. Optional `LocalVerifier` for explicitly trusted test fixtures, never production. Track source mutations and checks not executed; never auto-pass missing checks. Support change-specific baseline failure requirement when `CheckSpec.regression=True`.

## GitHub and publisher (`github.py`, `publisher.py`)

`GitHubClient(token_provider, transport: httpx.BaseTransport|None=None, api_url='https://api.github.com')`; token provider callable `(installation_id: int, repository_id: int, write: bool=False)->str`. `snapshot(policy: RepoPolicy, pr: int)->ChangeSnapshot` authoritatively fetches PR + paginated files/review threads, repo identities, current base/head and branch; reject closed/draft/fork states according to policy. `fetch(policy,snapshot,destination: Path)->GitWorkspace` fetch exact head/base through credential-minimal Git subprocess with hooks/global config disabled; source execution never inherits auth. `post_review(policy,snapshot,findings: tuple[Finding,...])->str` deterministic stable marker, anchor validation, reconcile existing comment, stale-head check. `checks(policy,snapshot)->dict` paginated, explicit actual head and conclusions. `AppTokenProvider(app_id,key_pem,transport=None)` scoped JWT and installation token endpoint, no broad-token cache leakage.

`Publisher(forge: GitHubClient, artifacts: ArtifactStore, approval_secret: bytes)`; `.publish(policy: RepoPolicy, candidate: Candidate, verification: Verification, approval: Approval, workspace: GitWorkspace)->dict`: verify signed approval and all candidate/evidence/policy/current-PR identities; refuse disabled publishing; clean reconstruct patch/commit, verify frozen object identities and actual parent/tree; expected-head atomic Git update, remote readback, ambiguous response reconciliation, no merge API. Model-produced worktree cannot be pushed directly. Expose `sign_approval(candidate,verification,actor,secret,expires_at)->Approval` shared pure helper in publisher for API use. No live writes in tests except local bare Git fixtures/mocked GitHub transport.

Root integrates worker pipeline and API after these modules land. Coordinate deviations immediately; tests drive behavior before implementation.
